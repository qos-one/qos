## QOS v0.1.7

> Start on a paper account. QOS is software, not financial advice: you are responsible for every order it sends.

A maintenance release: one crash fix for new installs, and easier first steps. Order, risk, sign-in and
AI control behaviour are the same as in v0.1.6.

**What you need to do:** nothing special. Update as usual. If you install the developer kit with `pip`,
use the new tag:

```
pip install "qos-sdk @ git+https://github.com/qos-one/qos.git@v0.1.7#subdirectory=qos_sdk"
```

### Fixed

- **First backtest crashed with pandas 3.** `frame_to_bars` passed read-only arrays to NautilusTrader
  when the bars had a `volume` column, so loading bars from a `qos data` export file stopped with
  "buffer source array is read-only". It now works with pandas 2 and pandas 3 (#25).
- **Python version for the developer kit.** `qos-sdk` now declares Python 3.12, 3.13 or 3.14
  (`>=3.12,<3.15`), so `pip` refuses an unsupported Python instead of failing later during install (#25).

### Getting started

- **Try it without a broker.** The README has a new section that runs a first backtest on generated
  bars, with no Interactive Brokers account. `qos new` now also writes `first_backtest.py` into a new
  strategy folder. Its output is labelled as coming from generated bars: it shows that the code runs,
  not how a strategy performs (#27).
- **Setup report form.** Issues now open with a form. The
  [Setup report](https://github.com/qos-one/qos/issues/new?template=1_setup_report.yml) form asks for
  your OS, Python version, the command you ran and its last lines of output. There are also forms for
  bugs, feature requests and questions. Security problems are still reported privately, as described
  in `SECURITY.md` (#26).
- **First-run documentation.** Corrected gateway ports for market data (IB Gateway paper 4002, TWS
  paper 7497), what `docker-compose.yml` runs (Redis only), where the local token file is and what
  the Terminal's 403 messages mean, and a new "After your first backtest" section (#19).
- **Walk-forward limits.** The README now states what the walk-forward report does and does not
  tell you (#26).

### AI wording

> Optional and experimental. AI can make mistakes; you are responsible for every order it places. Account data you share goes to your chosen AI provider. Keep your token secret. Software, not financial advice.

- Text only, no behaviour change: the README and the MCP reverse-proxy example now say that the AI
  can place orders (paper by default, live only if an admin turns it on), and that assistant trading
  is off until an admin turns it on (#14).

### Other

- `NOTICE`, `qos_sdk/NOTICE` and `TRADEMARKS.md` name the copyright and trademark holder as
  Dr. Seksin Cheevirot, the QOS Agent Exception text is final, and `TRADEMARKS.md` matches the policy
  published on qos.one (#20, #23).
- Tests: a test that failed depending on the calendar date now pins its clock (#28), and tests that
  need the `qos-examples` repository are skipped when it is not present (#26).
- Web Terminal v0.1.7 is in the [qos-terminal releases](https://github.com/qos-one/qos-terminal/releases/tag/v0.1.7)
  (`qos-terminal-web.tgz` and `qos-terminal-web.sha256`).

**Upgrade on a server:** run `sudo bash deploy/install.sh` again with the same settings, including
`QOS_TERMINAL_DOMAIN`. Note that `install.sh` pulls the latest `main`, which can be newer than the
`v0.1.7` tag, and installs the latest web Terminal release. Running strategy nodes are not stopped by
the update.
